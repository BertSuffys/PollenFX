  ----- conventions ----- 
-> Do not use get() or set() members. Always write proper getMethod() getters and setters.
-> Never acces properties. Always use the getters and setters. 
-> Only access members or properties that are documented.
-> parent properties must be accessed with this., parent methods with super.

  ----- Terminology ----- 
-> actTime = time (in ms) something is alive for
-> spawnTime = moment/date (in ms) when spawning
-> lifeTime = time (in ms) something should in total be alive for
-> liveTime = spawnTime + actTime, in essence.
-> fxItemId = id of either a particle or an emitter
-> active = ultimate identifier indicating that something can run, compiled from multiple flags
